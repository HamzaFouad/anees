# Anees — Claude Instructions

## Project

Windows 10/11 desktop app wrapping `yt-dlp` + `ffmpeg` to download YouTube playlists as sped-up MP3s, split, and merge them.

**Stack:** Python · PySide6 · subprocess · SQLite · PyInstaller

---

## Architecture rules

The project is split into two top-level packages with a strict dependency direction:

```
anees/
  ui/        ← PySide6 only
  backend/   ← Pure Python, no PySide6
  main.py    ← Entry point: wires ui ↔ backend
```

### `backend/` — Pure Python
- Contains: models, services, commands, storage
- **Never imports from `ui/`**
- No PySide6 imports anywhere in this package
- No subprocess calls from outside `backend/commands/`
- Services communicate results via return values or callbacks passed in by the caller

### `ui/` — PySide6 only
- Contains: widgets, dialogs, panels, theme, AppState
- May import from `backend/` for models and services
- AppState lives here (owns PySide6 Signals); backend services receive callbacks, not Signal refs
- No file I/O, no subprocess calls, no SQLite queries directly in widget code

### Communication pattern
```
ui/ calls → backend/services/  (passes callback or receives return value)
backend/services/ calls → backend/commands/  (subprocess)
backend/commands/ emits lines → callback → ui/ updates state
```

- App name: **Anees** (not "Mem")

- Config: `~/.anees/config.json`
- History DB: `~/.anees/history.db`

## Environment

- Python: **3.12** (use `python3.12 -m venv .venv` on macOS, `py -3.12 -m venv .venv` on Windows)
- Venv: `.venv/` at project root — always activate before running or installing
- Run: `.venv/bin/python main.py` (macOS) · `.venv\Scripts\python main.py` (Windows)
- Install: `.venv/bin/pip install -r requirements.txt`

## Key decisions

- Use `yt-dlp` **CLI executable**, not the Python API — the UI previews the exact command that runs
- Use `subprocess.Popen` with `CREATE_NO_WINDOW` and stream stdout/stderr line by line
- For atempo speed > 2.0: chain filters (`atempo=sqrt(N),atempo=sqrt(N)`)
- Background work runs in `QThread`; results post back to the main thread via Signals
- SQLite for history; JSON for config
- PyInstaller one-folder mode; vendor `yt-dlp.exe`, `ffmpeg.exe`, `ffprobe.exe` in `vendor/win-x64/`
