# Anees — Claude Instructions

## Project

Windows 10/11 desktop app wrapping `yt-dlp` + `ffmpeg` to download YouTube playlists as mono MP3s, optionally split into chunks, then merged into a flat folder.

**Stack:** Python 3.12 · PySide6 · yt-dlp Python SDK · ffmpeg · PyInstaller

---

## Architecture rules

```
ui/api/           ← UI action layer (RunAPI, QueueAPI, NavAPI)
ui/workers/       ← QThread wrappers (DownloadWorker, InfoWorker)
ui/panels/        ← display widgets (read AppState, call ui/api/)
ui/dialogs/       ← modal dialogs

backend/api/      ← public contract for ui/ (DownloadAPI, InfoAPI, SplitAPI, …)
backend/services/ ← internal orchestration — NEVER imported by ui/
backend/commands/ ← tool wrappers (YtdlpClient, FfmpegClient)
backend/utils/    ← pure functions (audio size, config)
backend/models.py ← shared dataclasses
```

### Allowed backend imports from `ui/`
| Module | Allowed? | Reason |
|--------|----------|--------|
| `backend.models` | ✅ | Shared dataclasses, no logic |
| `backend.api` | ✅ | The only gateway to backend services |
| `backend.mock_data` | ✅ temporarily | Replaced by real storage in Phase 9 |
| `backend.services.*` | ❌ | Use `backend.api` |
| `backend.commands.*` | ❌ | Implementation detail |
| `backend.storage.*` | ❌ | Use `backend.api` |

### Communication pattern
```
ui/ → backend/api/ → backend/services/ → backend/commands/ → yt-dlp / ffmpeg
       only entry         internal            tool wrappers
       point for ui
```

### AppState signals
- `playlists_changed` — sidebar refresh only; **throttled to video completions** during a run — never emit on every progress tick
- `selection_changed` — detail panel rebuild; emit only at structural changes (videos loaded, run complete)
- `video_row_changed(pid, idx)` — in-place single row update; does NOT rebuild the panel

## Key decisions (see `docs/decisions.md` for full rationale)

- yt-dlp **Python SDK** — `import yt_dlp` only in `backend/commands/ytdlp.py`
- Output: CBR 192 kbps mono MP3 (`FFmpegExtractAudio`, `-ac 1`)
- Pipeline order: DL → MP3 → /Split → ×Speed
- postprocess_hook trigger: check `filepath.endswith('.mp3') and exists` — NOT `postprocessor=='FFmpegExtractAudio'` (fragile)
- ffmpeg subprocess for split/speed; yt-dlp SDK for download/convert
- Background work in `QThread`; results back via Signals (queued connections)
- SQLite for history (Phase 9); JSON for config

## Qt pitfalls (critical — repeat offenders)

- **Border cascade**: never set `border-*` on a container QWidget — it cascades to all children. Use `#id { border: ... }` selectors.
- **Separator**: always use a dedicated 1px `QFrame`, never `border-bottom` on a widget.
- **Visual ownership**: container owns base surface (bg/border/radius); rows inside tinted containers stay transparent by default.
- **Override precedence**: theme tokens → `ui/widgets.py` helpers/primitives → scoped `#id` local styles → `paintEvent` (last resort).
- **Token discipline**: prefer `ui/theme.py` tokens (`PRIMARY_TINT_*`, `BORDER`, `ROW_DIVIDER`) over hardcoded rgba/hex in UI code.
- **Spinner segfault**: call `sp.stop()` + `w.hide()` before `deleteLater()` on any widget that contains a `Spinner`.
- **No I/O in toolbar refresh**: `refresh()` is called on every `playlists_changed` signal — never call `shutil.disk_usage` or `Path.mkdir` there.
- **Signal GC**: lambdas as slots in `refresh()` get silently garbage-collected. Use bound methods (`_do_start`, `_do_pause`, etc.).
- **Thread signals**: `Signal(str, list)` can fail across threads — use `Signal(str, object)`.
- **ScrollBar misalignment**: set `ScrollBarAlwaysOff` on the video rows `QScrollArea` so its viewport width always matches the `_ColHeader` above it.
